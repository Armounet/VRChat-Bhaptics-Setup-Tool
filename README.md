# **VRChat Bhaptics Setup Tool**

This tool simplifies the process of setting up Bhaptics haptic feedback on VRChat avatars within Unity.

---

## **Purpose**

To facilitate easy integration of Bhaptics on VRChat avatars in the Unity editor.

---

## **Features**

* Automatically creates and removes the Bhaptics menu and parameters.
* Automatically sets up and removes necessary animation layers and parameters for Bhaptics.

---

## **How to get started**

1.  Import the provided [**`VRChat-Bhaptics-Setup-Tool.unitypackage`**](https://github.com/Armounet/VRChat-Bhaptics-Setup-Tool/releases/)).
2.  Navigate to the **`VRChat Bhaptics Setup`** menu at the top of your Unity editor window.
3.  Select either **`Bhaptics Setup`** or **`Animation Setup`**.
4.  Follow the on-screen instructions to select or drag your desired avatar.

---

## **Prerequisites**

* Unity Editor (latest recommended for VRChat).
* VRChat SDK3 - Avatars.
* **Important:** Your avatar must be already set up with **Bhaptics OSC**: [**Bhaptics OSC Setup**](https://github.com/bhaptics/VRChatOSC)

---

## **Installation**

1.  Download the [**`VRChat-Bhaptics-Setup-Tool.unitypackage`**](https://github.com/Armounet/VRChat-Bhaptics-Setup-Tool/releases/) from the Releases page.
2.  Import the downloaded `VRChat-Bhaptics-Setup-Tool.unitypackage` into your Unity project.
